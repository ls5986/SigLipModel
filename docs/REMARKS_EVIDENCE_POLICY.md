# Remarks condition evidence policy

The saved candidate has 578 predictions. The metadata combiner used TARGET from either text or structured features, and let uncertain structured fields block learned NOT_TARGET text. Strong renovation statements could be overridden by indirect age/size correlations.

This patch adds a versioned, deterministic application policy to the web projection and cached-score API response. Original prediction documents, dataset memberships, labels, model artifacts and evaluation metrics are untouched. It is not new training or human review.

Explicit dated/updating statements qualify weak TARGET even with partial upgrades. Explicit whole-property renovation statements qualify metadata NOT_TARGET in the absence of dated evidence. A decisive learned remarks NOT_TARGET is no longer blocked by unknown structured input. Quartz, stainless steel and move-in ready alone are not proof of fully renovated condition. Negated/future renovations and room-only renovations are excluded from whole-home rules. Photo results remain independent. Overall TARGET strength is the strongest qualifying axis, without a separate fusion boost.

The UI labels this evidence policy, exposes original learned metadata, deduplicates parsed signals and reference quotes. Automated projections never mark records human reviewed. The JSON audit records decision changes for all existing predictions. Further semantic or historical ambiguity still requires review.
